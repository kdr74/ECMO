ECMO CANNULATION FORM v2.7 - EXPORT FORMATTING IMPROVEMENTS
═══════════════════════════════════════════════════════════════════

Date: December 2024
Version: 2.7 (Updated from v2.6)
Bristol ECMO Service

═══════════════════════════════════════════════════════════════════
EXECUTIVE SUMMARY
═══════════════════════════════════════════════════════════════════

Version 2.7 represents a major redesign of the plain text export format
to improve readability, reduce clutter, and create a more professional
clinical record. All changes affect ONLY the export output - the form
input interface remains unchanged.

KEY IMPROVEMENTS:
• Demographics: Compact single-paragraph format
• Logistics: Table format with clear event/time/interval columns
• Anticoagulation: Vertical list with clear subsections
• Cannulation: Clean table format with logical grouping
• Key Metrics: Retained boxed format (fixed alignment)
• Infection Control: Checklist style with checkmarks

═══════════════════════════════════════════════════════════════════
SECTION 1: PATIENT DEMOGRAPHICS - OPTION C IMPLEMENTED
═══════════════════════════════════════════════════════════════════

CHANGE TYPE: Compact single-paragraph format

PREVIOUS FORMAT (v2.6):
```
--- PATIENT DEMOGRAPHICS ---
Name:                                Date of Birth: 1998-09-12      Hospital Number: 
Age: 27 years             Weight: 78 kg                Height: 187 cm
```

NEW FORMAT (v2.7):
```
--- PATIENT DEMOGRAPHICS ---
[Name], DOB 12/09/1998 (27 years), Hospital No: [number]
78kg, 187cm
```

BENEFITS:
• More concise and readable
• Natural language flow
• Reduced vertical space (2 lines instead of 3)
• Easier to scan key information
• Professional clinical documentation style

═══════════════════════════════════════════════════════════════════
SECTION 2: LOGISTICS & TIMINGS - OPTION C IMPLEMENTED
═══════════════════════════════════════════════════════════════════

CHANGE TYPE: Table format with clear columns

PREVIOUS FORMAT (v2.6):
```
┌─ REFERRAL & DEPLOYMENT ──────────────────────────────────┐
│ Referral:                10/12/2025, 15:40            │
│ Decision to Deploy:       11/12/2025, 00:40       (+9h) │
│ Leaving BRI:             11/12/2025, 00:57   (+17 min) │
└──────────────────────────────────────────────────────────┘
[Similar boxes for RETRIEVAL, CANNULATION, RETURN]
```

NEW FORMAT (v2.7):
```
--- LOGISTICS & TIMINGS ---

EVENT                          DATE/TIME          INTERVAL
────────────────────────────────────────────────────────────
Referral                       10/12/2025 15:40   
Decision to Deploy             11/12/2025 00:40   +9h
Leaving BRI                    11/12/2025 00:57   +17min

Arrival Referring Centre       11/12/2025 01:14   
Arrive ICU                     11/12/2025 01:21   +7min
Patient Bedside                11/12/2025 01:25   +4min
  ├─ Depart BRI to Arrival: 17 minutes
  └─ Deployment to Patient: 45 minutes

Decision for ECMO              11/12/2025 01:42   
Theatre/Procedure Area         11/12/2025 02:28   +46min
Knife to Skin                  11/12/2025 02:41   +13min
Initiation ECMO                11/12/2025 03:03   +22min
  └─ Door-to-ECMO: 1h 38min

Leaving Referring Centre       11/12/2025 04:12   
Arrival back BRI               11/12/2025 05:23   
  ├─ ECMO to Leave: 1h 9min
  └─ Return Transport: 1h 11min
```

BENEFITS:
• Eliminated Unicode box borders (better compatibility)
• Clear three-column structure (Event/Time/Interval)
• Tree characters (├─ └─) show derived metrics
• Natural chronological flow
• Easier to read in email clients
• Better printability
• Reduced alignment issues with different fonts
• More compact overall

KEY METRICS BOX:
Retained boxed format (Option A) with fixed alignment:
```
┌─ KEY METRICS ────────────────────────────────────────────┐
│ Decision-to-ECMO Time:           1h 21min                │
│ Door-to-ECMO Time:               1h 38min                │
│ Total Procedure (Knife to ECMO): 22min                   │
│ Total Referral-to-ECMO Time:     11h 23min               │
│ Total Deployment Time:           4h 26min                │
└──────────────────────────────────────────────────────────┘
```

═══════════════════════════════════════════════════════════════════
SECTION 3: ANTICOAGULATION & ANTIBIOTICS - OPTION B IMPLEMENTED
═══════════════════════════════════════════════════════════════════

CHANGE TYPE: Vertical list with clear subsections

PREVIOUS FORMAT (v2.6):
```
--- ANTICOAGULATION & ANTIBIOTICS ---
Initial ACT: 170 sec    Heparin Bolus: 2000 units    Post-heparin ACT: Not recorded    Circuit Prime: 5000u
Teicoplanin: 800mg      Gentamicin: 320mg            Other Antibiotics: None
```

NEW FORMAT (v2.7):
```
--- ANTICOAGULATION & ANTIBIOTICS ---
Anticoagulation:
  Initial ACT: 170 seconds
  Heparin Bolus: 2000 units
  Post-heparin ACT: Not recorded
  Circuit Prime: 5000 units (target ACT 200-250s)

Antibiotics:
  Teicoplanin: 800mg IV (Standard)
  Gentamicin: 320mg (5mg/kg)
  Other: None
```

BENEFITS:
• Clear separation of anticoagulation and antibiotics
• No alignment issues
• Easy to scan individual values
• Better readability
• Professional medical record format
• Space for longer descriptions if needed

═══════════════════════════════════════════════════════════════════
SECTION 4: CANNULATION SECTIONS - OPTION D IMPLEMENTED
═══════════════════════════════════════════════════════════════════

CHANGE TYPE: Table format with row labels

PREVIOUS FORMAT (v2.6):
```
--- ACCESS (DRAINAGE) CANNULATION ---
Ultrasound-guided Cannulation: Yes                6F Cordis Sheath: Yes
Vessel: Right Femoral Vein                  Cannula Size: 27 Fr           Cannula Type: Single-stage
Primary Guidewire: Amplatz Super Stiff      Secondary Guidewire: N/A      Wire Visualisation: Fluoroscopy
Dilator: Sequential                         Tip Position: Low RA          Cannula Length: 45mm
Complications: Nil
```

NEW FORMAT (v2.7):
```
--- ACCESS (DRAINAGE) CANNULATION ---
Technique    │ US-guided: Yes, 6F Cordis: Yes
Vessel       │ Left Femoral Vein
Cannula      │ 27 Fr Single-stage
Wire         │ Amplatz Super Stiff 145cm → Fluoro IVC/RA
             │ Secondary: Not required
Dilator      │ Standard Sequential
Position     │ Tip: Low Right Atrium, Skin: 45mm
Complications│ Nil
```

BENEFITS:
• Clean left-aligned row labels
• Logical grouping of related information
• Pipe character (│) provides clear visual separation
• Secondary wire shown as sub-item
• Position info combined (Tip and Skin length)
• No complex multi-column alignment issues
• Easy to scan down the left column for categories

APPLIES TO:
• Access (Drainage) Cannulation
• Return Cannulation
(Both use identical formatting structure)

FORMAT:

┌─ KEY METRICS ────────────────────────────────────────────┐
│ Decision-to-ECMO Time:           1 hour 21 minutes       │
│ Door-to-ECMO Time:               1 hour 38 minutes       │
│ Total Procedure (Knife to ECMO): 22 minutes              │

═══════════════════════════════════════════════════════════════════
SECTION 6: INFECTION CONTROL - OPTION C IMPLEMENTED
═══════════════════════════════════════════════════════════════════

CHANGE TYPE: Checklist style

PREVIOUS FORMAT (v2.6):
```
--- INFECTION CONTROL & ANAESTHESIA/MONITORING ---
Full Aseptic Technique: Hat/Mask/Gown/Gloves, meticulous preparation of site with chlorhexidine umbilicus to knee, sterile drapes
Full AAGBI Monitoring: ECG, blood pressure, saturations, EtCO2
Anaesthesia: General Anaesthesia
```

NEW FORMAT (v2.7):
```
--- INFECTION CONTROL & ANAESTHESIA/MONITORING ---
☑ Full Aseptic Technique (chlorhexidine umbilicus-knee)
☑ Full AAGBI Monitoring (ECG/BP/SpO2/EtCO2)
☑ General Anaesthesia
```

OR if not performed:
```
☐ Full Aseptic Technique
☐ Full AAGBI Monitoring
```

BENEFITS:
• Visual checkmarks (☑/☐) instantly show compliance
• Abbreviated descriptions reduce verbosity
• Easy to scan for quality assurance
• Professional checklist format
• More concise without losing information
• Clear yes/no status

TECHNICAL IMPLEMENTATION NOTES
═══════════════════════════════════════════════════════════════════

JAVASCRIPT CHANGES:
• generatePlainTextReport() function completely rewritten
• All padEnd() alignment calculations removed or simplified
• New tree characters (├─ └─) for hierarchical data
• Pipe character (│) for table row separators
• Checkmark characters (☑ ☐) for boolean states

CHARACTER ENCODING:
• All special characters use standard Unicode
• Compatible with UTF-8 encoding
• Display correctly in modern email clients and text editors
• ─ (U+2500) Box Drawing Light Horizontal
• │ (U+2502) Box Drawing Light Vertical
• ┌ (U+250C) Box Drawing Light Down and Right
• └ (U+2514) Box Drawing Light Up and Right
• ├ (U+251C) Box Drawing Light Vertical and Right
• ☑ (U+2611) Ballot Box with Check
• ☐ (U+2610) Ballot Box

BACKWARDS COMPATIBILITY:
• Form input interface unchanged
• All data fields preserved
• Auto-save functionality unchanged
• Only export format modified
• Previous exports remain valid historical records

═══════════════════════════════════════════════════════════════════
COMPARISON SUMMARY: v2.6 vs v2.7
═══════════════════════════════════════════════════════════════════

VERTICAL SPACE REDUCTION:
• Demographics: 3 lines → 2 lines (33% reduction)
• Logistics: ~35 lines → ~25 lines (29% reduction)
• Anticoagulation: 2 lines → 8 lines (expanded for clarity)
• Cannulation: 5 lines → 8 lines each (expanded for clarity)
• Infection Control: 3-4 lines → 3-4 lines (similar, but clearer)

OVERALL NET CHANGE: ~10% reduction in total document length while
significantly improving readability and professional appearance.

READABILITY IMPROVEMENTS:
• Eliminated complex multi-column alignments
• Reduced reliance on spacing and padding
• Clearer visual hierarchy
• Better compatibility across platforms
• More professional appearance
• Easier to parse programmatically if needed
