# VA-ECMO Clinical Guidelines and Tools

Interactive clinical decision support tools for Veno-Arterial ECMO management at UHBW Bristol.

## 🚀 Quick Access

**Live Site:** [https://kdr74.github.io/ECMO/va-ecmo/](https://kdr74.github.io/ECMO/va-ecmo/)

## 📋 Contents

### Interactive Tools
1. **[Weaning Study Form](tools/weaning-form.html)** - Structured weaning assessments with auto-calculations
2. **[PCRTO Assessment](tools/pcrto-assessment.html)** - Pump-Controlled Retrograde Trial Off protocol
3. **[Risk Stratification](tools/risk-stratification.html)** - ECMO candidacy risk assessment
4. **[E-CPR Algorithm](tools/ecpr-algorithm.html)** - Emergency CPR activation decision support

### Guidelines
- [Complete PDF Guideline](guidelines/VA_ECMO_UHBW_V1_8.pdf) - VA-ECMO UHBW V1.8
- [Weaning Protocol](guidelines/Standardised_VA-ECMO_Weaning_Protocol.rtf)
